**Project Title**:
# Cloud-Grocery-List #

**Project Description**:
This project will update a grocery list that exists on the cloud and include information about the locations and prices of various items.

**Project Goals**:

## Instructions for Build and Use

Steps to build and/or run the software:

1. Download and install MySQL.
2. Install the firebase-admin module.
3. Get a .json file with credentials to access the database.

Instructions for using the software:

1. Open the firebase_interface.py file in Visual Studio Code and hit run.
2. To add data about a grocery to the list, simply change the name, isle, company, and price of the item named grocery in the file and then run it.
3. To remove data from the database, just change the name of one of the items being deleted to the name of the item you want to delete from the database.

## Development Environment 

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* MySQL version 8.0.41.0
* Python version 3.11.2 - 64 bit
* Visual Studio Code version 1.96.4
* firebase-admin version 6.6.0
